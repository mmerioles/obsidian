The RSA Digital Signature Scheme
=

For given message x, digital signature appended to message, generated by person with private key

Security Services
- Confidentiality
- Integrity
- Message Authentication
- Non-repudiation
- Identification
- Access control
- Availability
- Auditing
- Physical Security
- Anonymity

Main Ideas
- To generate private and public key
- To generate the signature - "encrypt" message x with private key
- To verify the signature - "decrypt" signature with public key
