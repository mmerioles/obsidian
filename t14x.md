step 1. setting up the pico

using fedora kde 44... needed to install the following packages

sudo chown -R matt:matt /opt
git clone https://github.com/raspberrypi/pico-sdk


`vi ~/.bashrc`

```bash
export PICO_SDK_PATH=/opt/pico-sdk
export PICO_EXAMPLES_PATH=/opt/pico-examples
```

Then
`source ~/.bashrc`
 
Installed some build related packages
```bash
sudo dnf install arm-none-eabi-gcc-cs arm-none-eabi-newlib arm-none-eabi-gcc-cs-c++
sudo dnf group install development-tools
sudo dnf install gcc-c++
```

Getting the sdk and examples
```bash
cd /opt
git clone https://github.com/raspberrypi/pico-sdk
git clone https://github.com/raspberrypi/pico-examples

# make sure you run this within each
git submodule update --init
```

Trying to build the examples
```bash
cd pico-examples
mkdir build
cd build
cmake ..
cd blink
make
```

Then I hold the reset button on the pico, and insert it into laptop, mount it, and copy the files over

```bash
cp blink.uf2 /run/media/matt/RPI-RP2/
```

Now the pico is blinking :)


Now to run the hello world script

```bash
cd build
cd hello_world
make 
cd usb
cp hello_usb.uf2 /run/media/matt/RPI-RP2/
```

Need to install screen to see the output
```bash
sudo dnf install screen
# to find the below, just do `sudo dmesg`
sudo screen /dev/ttyACM0 115200
```
